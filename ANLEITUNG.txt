ARCHIPELAGO LAUNCHER – Super Mario 64 + Ocarina of Time
=======================================================

Was du brauchst
---------------
- Windows 10 oder 11 (64 Bit) und Internet
- Deine eigene ROM (wird NICHT mitgeliefert):
    * Super Mario 64: USA- oder Japan-Version (.z64 / .n64 / .v64)
    * Ocarina of Time: jede Version außer Master Quest
  ZIP-Dateien vorher entpacken.

Starten
-------
1. ZIP entpacken (Rechtsklick -> "Alle extrahieren") und ArchipelagoLauncher.exe starten.
2. Falls "Der Computer wurde durch Windows geschützt" erscheint:
   "Weitere Informationen" -> "Trotzdem ausführen".
   (Das Programm ist nur nicht digital signiert.)

Einrichten (einmalig, Tab "⚙ Einrichtung")
------------------------------------------
1. Spielername eintragen (max. 16 Zeichen, jeder einen anderen Namen).
2. Dein Spiel anklicken (Karte) und mit "Durchsuchen ..." deine ROM wählen.
   Ein grüner Haken zeigt, dass die ROM passt.
3. "Installieren / Prüfen" klicken und warten:
    * Ocarina of Time: ca. 5 Minuten
    * Super Mario 64: ca. 10-15 Minuten (das Spiel wird auf deinem PC gebaut)
   Alles landet in C:\APLauncher.
   Fragt Windows "Möchten Sie zulassen, dass diese App Änderungen vornimmt?"
   (beim Installieren von Archipelago): "Ja".
4. Optional: "YAML bearbeiten" bzw. "Options Creator" für Spieleinstellungen.
   Mario 64: Häkchen "Kamera links/rechts tauschen", OoT: "SoH Mods / Texturen".

Mitspielen (Tab "🎮 Spielen")
-----------------------------
1. Die Adresse vom Host bei "Server-Adresse" eintragen (z. B. 84.123.45.67:38281)
   und ggf. das Passwort.
2. "Beitreten" klicken. Du siehst dich in der Spielerliste.
3. Wenn der Host startet, wird "▶ Spielen" klickbar.
    * Mario 64 verbindet sich automatisch.
    * Ocarina of Time: auf dem Titelbildschirm einen NEUEN Spielstand anlegen und
      dabei "Archipelago" wählen. Jede neue Multiworld braucht einen neuen Spielstand.

Overlay (Ziele und "wohin als Nächstes")
----------------------------------------
Sobald du verbunden bist: "🗺 Overlay" klicken. Ein kleines Fenster bleibt über dem Spiel und zeigt:
  * dein Ziel und wie weit du bist (z. B. Sterne, Amulette, Schlüssel)
  * alle Orte, die du mit deinen aktuellen Items erreichen kannst, nach Gebiet sortiert
    (aufklappen für die einzelnen Orte, ★ = Hinweis von einem Gossip Stone o. ä.)
  * die zuletzt erhaltenen Items
Es aktualisiert sich bei jedem Fund von selbst.

Hosten
------
1. Tab "🎮 Spielen": "Server hosten" klicken. Die Adresse für Freunde steht grün im
   Fenster – anklicken kopiert sie.
   Nutzt ihr Radmin VPN/Hamachi: im Tab "🌐 Netzwerk" einmal auf den erkannten
   "Radmin: 26.x.x.x"-Knopf klicken, dann wird diese Adresse angezeigt.
2. Tab "🌐 Netzwerk": "Port testen". Ist der Port erreichbar, können Freunde direkt mit deiner Adresse beitreten.
   Fragt die Windows-Firewall nach: "Zulassen".
   Ist er NICHT erreichbar, gibt es zwei Wege:
   a) Portfreigabe im Router, z. B. FRITZ!Box: http://fritz.box -> Internet -> Freigaben ->
      Portfreigaben -> Gerät (deinen PC) hinzufügen -> Neue Freigabe -> Portfreigabe,
      TCP, Port 38281 bis 38281, extern 38281.
   b) playit.gg (ohne Router): Knopf "playit.gg" im Launcher.
      - Beim ersten Mal wird playit installiert (Windows fragt nach Admin-Rechten) und
        einmalig mit einem kostenlosen playit-Konto verbunden (Link im Fenster öffnen).
      - Dann öffnet sich die Tunnel-Seite: "Add Tunnel", Typ TCP (KEIN Spiel auswählen),
        Local Address 127.0.0.1, Local Port 38281, speichern.
      - Die Tunnel-Adresse (z. B. abc.gl.at.ply.gg:12345) im Launcher-Fenster einfügen.
        Ab dann steht sie als "Adresse für Freunde" im Launcher (anklicken = kopieren).
      - playit läuft im Hintergrund (Symbol unten rechts in der Taskleiste).
3. Wenn alle in der Liste sind: "Multiworld starten".
4. Weiterspielen an einem anderen Tag: "Spielstand fortsetzen ...".

Probleme
--------
- "Der Host ist ... nicht erreichbar": Adresse prüfen, Host muss "Server hosten" geklickt
  haben, sonst fehlt beim Host die Portfreigabe -> playit.gg nutzen.
- "... ist in der laufenden Multiworld nicht dabei": Der Host muss "Beenden"
  und dann "Server hosten" klicken, danach erneut "Beitreten".
- OoT trennt sofort ("incorrect slot"): neuen Archipelago-Spielstand anlegen.
- Fehler mit "VCRUNTIME140.dll": "Microsoft Visual C++ Redistributable x64" von
  microsoft.com installieren.
- SoH-Texturpakete (.o2r/.otr): Button "SoH Mods/Texturen".
- Mario 64: Häkchen "Kamera links/rechts tauschen" vor dem Spielstart setzen.
